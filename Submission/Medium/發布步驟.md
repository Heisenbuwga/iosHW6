# 發布與繳交

1. 使用 Xcode 開啟 iosHW6.xcodeproj，執行確認。
2. GitHub 專案：https://github.com/Heisenbuwga/iosHW6
3. 將 Medium文章草稿.md 的文字貼到 Medium，依圖片標記插入 Demo/images 下的實際截圖。
4. 將本資料夾的 TeaAtelier-iPhone-demo.mp4 與 TeaAtelier-iPad-demo.mp4上傳到文章支援的影音平台後嵌入。
5. 補上 GitHub repository URL 與影片 URL，預覽後發布。
6. 繳交 Medium 文章 URL 和 GitHub URL。

影片保留在本機文章資料夾，不納入 Git 追蹤。文章預覽可直接播放兩支影片。

此資料夾提供可編輯草稿；Medium 由使用者自行發布。
